# Stone-Paper-Scissors in C

A console-based Stone-Paper-Scissors game built in C as a BCA 1st year Data Structures project at Chandigarh University.

## Features
- Play multiple rounds with score tracking
- Input validation — handles invalid entries gracefully
- Smart AI mode that predicts your most frequent move
- Session summary at the end (win / lose / draw)

## How to compile and run
```bash
gcc sps.c -o sps
./sps
```

## Game controls
| Input | Move |
|-------|------|
| 0 | Stone |
| 1 | Paper |
| 2 | Scissors |
